# OrignaBase — Repository Map

## Quick Navigation

### Binary & CLI
- `crates/orignabase/src/main.rs` — Entry point, Axum server setup, route composition, CLI (clap)
- `crates/orignabase/tests/integration_test.rs` — 50+ live integration tests (requires running server)
- `crates/orignabase/benches/core_benchmarks.rs` — Criterion benchmarks

### Build Hygiene
- `scripts/cargo-target-dir.sh` — Shared helper that routes Cargo output into `target/dev`, `target/test`, `target/coverage`, or `target/release`
- `scripts/test-all.sh` — Uses isolated Cargo target buckets for workspace tests, live tests, and clippy
- `scripts/coverage.sh` — Uses the dedicated `target/coverage` bucket for `cargo llvm-cov`
- `scripts/clean_rust_artifacts.sh` — Removes managed Rust build artifacts and optionally legacy `target/debug` leftovers
- `scripts/check_rust_artifacts_size.sh` — Fails when `target/` exceeds `ORIGNABASE_MAX_TARGET_GB` (default `30`)
- `scripts/install_git_hooks.sh` — Installs a `pre-push` hook that runs the Rust artifact size check
