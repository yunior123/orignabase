# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in OrignaBase, please report it responsibly:

1. **Do not** open a public GitHub issue
2. Email: security@orignabase.dev (or open a private security advisory on GitHub)
3. Include: description, reproduction steps, impact assessment

We aim to respond within 48 hours and release a fix within 7 days for critical issues.

|---------|-----------|
